# OCR Lab — Garmin FINAL V4.2.2

Esta es la versión Garmin congelada para integración en Corredor Sólido.

## Campos comprobados

- Fuente
- Tipo de pantalla
- Título
- Lugar
- Actividad
- Fecha
- Hora
- Distancia
- FC media
- FC máxima
- Ritmo medio
- Tiempo total
- Calorías
- Cadencia
- Desnivel positivo

La temperatura queda como `No encontrado` cuando no aparece en ninguna captura.

## Flujo recomendado

1. Subir una captura de `Resumen`.
2. Subir las capturas necesarias de `Estadísticas`.
3. Revisar las métricas fusionadas.
4. Copiar o integrar el JSON final.
